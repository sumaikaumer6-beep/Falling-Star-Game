# Falling Star Game ⭐

A simple **Falling Star Game** developed using **Python and Pygame**. The player controls a character/object and tries to avoid or catch falling stars while earning points.

## 🎮 Features

* ⭐ Falling star animation
* 🏆 Score system
* 🎵 Background music support
* 🖥️ Simple and user-friendly game window
* 🔄 Game restart functionality
* 🔌 Backend API integration

## 🛠️ Technologies Used

* **Python**
* **Pygame**
* **Backend API**
* **Git & GitHub**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/sumaikaumer6-beep/Falling-Star-Game.git
```

### 2. Open the project

```bash
cd falling-star-game
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the game

```bash
python main.py
```
