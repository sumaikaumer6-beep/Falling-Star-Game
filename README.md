# Falling Star Game
A Pygame game where you catch falling stars and make a high score

## Features
- Start Menu and Game Over Screen
- High Score is saved in `highscore.txt`
- Clean code with comments
- Smooth controls and sound effects

## How to Run
1. Install Python 3.8 or higher
2. Install required library:
`pip install pygame`
3. Run the game:
`python main.py`
4.Leaderboard uses Django REST API:[https://github.com/sumaikaumer6-beep/django-leaderboard-api]
